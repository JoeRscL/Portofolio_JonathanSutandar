# 🌐 Personal Portfolio Website

Website portofolio pribadi yang modern dan interaktif, dirancang untuk menampilkan pengalaman kerja, proyek, dan keahlian teknis saya sebagai **Frontend Developer**.

Website ini dibangun dengan fokus pada desain yang bersih, minimalis, dan mudah dipahami — dibuat dengan perhatian terhadap detail agar nyaman dibaca di layar kecil maupun besar.

## 🚀 Live Demo

https://portofolio-jonathansutandar.vercel.app/

## ✨ Fitur Utama

* **Responsive Design:** Tampilan menyesuaikan sempurna di Desktop, Tablet, dan Mobile.
* **Smooth Animations:** Transisi halus menggunakan Framer Motion.
* **Desain Minimalis:** Layout yang bersih, ruang yang cukup, tidak berlebihan.
* **Proyek Pilihan:** Galeri proyek unggulan dengan kategori (Web, Android, AI/ML, Game, UI/UX).
* **Interactive Contact:** Tombol kontak langsung ke WhatsApp, Email, LinkedIn.
* **Downloadable CV:** Fitur unduh Resume/CV langsung dari website.

## 🛠️ Teknologi yang Digunakan

Project ini dibangun menggunakan *tech stack* modern berikut:

* **[React.js](https://reactjs.org/)** - Library JavaScript utama untuk antarmuka pengguna.
* **[Vite](https://vitejs.dev/)** - Build tool yang sangat cepat untuk frontend modern.
* **[Framer Motion](https://www.framer.com/motion/)** - Library untuk animasi kompleks.
* **[Lucide React](https://lucide.dev/)** - Koleksi ikon open-source ringan.
* **CSS3** - Custom styling untuk layout, responsivitas, dan animasi.

## 📂 Struktur Proyek

Berikut adalah gambaran singkat isi website ini:

1.  **Hero Section:** Perkenalan diri, status ketersediaan, dan tombol aksi cepat.
2.  **Experience:** Riwayat pekerjaan profesional secara kronologis.
3.  **Proyek Pilihan:** Daftar proyek unggulan (Web, Android, AI/ML, Game Dev).
4.  **Keahlian:** Daftar kemampuan teknis yang dikelompokkan (Bahasa, Framework, Tools).
5.  **Contact:** Informasi kontak media sosial dan profesional.

## 📦 Cara Menjalankan di Lokal

Jika ingin menjalankan project ini di komputer Anda, ikuti langkah berikut:

1.  **Clone repository ini:**

    ```bash
    git clone https://github.com/JoeRscL/Portofolio_JonathanSutandar
    ```

2.  **Masuk ke direktori project:**

    ```bash
    cd Portofolio_JonathanSutandar
    ```

3.  **Install dependencies:**

    ```bash
    npm install
    ```

4.  **Jalankan server development:**

    ```bash
    npm run dev
    ```

5.  **Buka browser** dan akses `http://localhost:5173`.

## ☁️ Cara Hosting di Vercel

### Langkah 1 — Siapkan repository
Pastikan project sudah di GitHub:

```bash
git remote set-url origin https://github.com/JoeRscL/Portofolio_JonathanSutandar
git push -u origin main
```

### Langkah 2 — Import ke Vercel
1.  Buka [Vercel Dashboard](https://vercel.com/dashboard).
2.  Klik **Add New Project**.
3.  Pilih repository `JoeRscL/Portofolio_JonathanSutandar`.
4.  Konfigurasi build (secara otomatis terdeteksi):
    * **Framework Preset:** `React`
    * **Root Directory:** (leave empty)
    * **Build Command:** `npm run build`
    * **Output Directory:** `dist`

### Langkah 3 — Deploy
5.  Klik **Deploy**.
6.  Tunggu sampai selesai (biasanya 1–2 menit).
7.  Setelah selesai, Vercel akan memberikan URL, misalnya:
    `https://portofolio-jonathansutandar.vercel.app`

### Langkah 4 — Verifikasi
* Buka URL yang diberikan.
* Pastikan semua section tampil dengan benar:
  * Hero
  * Experience
  * Proyek Pilihan
  * Keahlian
  * Contact
* Cek tampilan di mobile (via browser dev tools).
